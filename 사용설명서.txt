============================================================
  인스타 사진 다운로더  ·  사용설명서
============================================================

인스타그램 '공개 계정'의 사진을
  · 12개씩 목록으로 보고 → 원하는 것만 골라 → 원본 화질로 받고
  · 고른 것만 ZIP 하나로 묶어 받는 프로그램입니다.

집 PC에서 켜 두고 폰으로 접속할 수도 있고,
인터넷(GitHub + Render)에 올려 링크로 쓸 수도 있습니다.

------------------------------------------------------------
0. 이번에 새로 생긴 것 (한눈에)
------------------------------------------------------------
  ✔ 목록으로 보기 ........... 아이디를 넣으면 12개씩만 보여 줍니다.
                              [다음 12개 더 불러오기]로 조금씩만 더 가져옵니다.
  ✔ 골라서 받기 ............. 체크한 사진만 원본 화질로, 또는 ZIP으로 받습니다.
  ✔ 다운 완료 표시 .......... 이미 받은 사진은 흐리게 + '다운 완료' 표시.
                              [안 받은 사진만 보기]로 숨길 수 있습니다.
  ✔ 차단 방지 ............... 요청 사이 1.5~3초 무작위 대기, 목록 캐시,
                              연속 새로고침 10초 쿨다운.
  ✔ 로그인 세션 ............. 인스타가 '로그인 필요'라고 할 때 sessionid를 넣어 해결.
  ✔ 클라우드 배포 ........... Render.com 무료로 올려 https 링크로 사용 가능.

------------------------------------------------------------
1. 준비물
------------------------------------------------------------
  · (집에서 쓸 때) 윈도우 PC + 같은 와이파이의 폰/노트북
  · (클라우드로 쓸 때) GitHub 계정, Render 계정, 인터넷만 있으면 됨
  · Python 3.9 이상  (집 PC에서 돌릴 때만 필요)

------------------------------------------------------------
2. 처음 한 번만: Python 설치 (집 PC)
------------------------------------------------------------
  1) https://www.python.org/downloads/ 접속
  2) 가운데 노란 [Download Python 3.x.x] 버튼 → 내려받기 → 실행
  3) ★ 설치 첫 화면 맨 아래
        [ ] Add python.exe to PATH
     를 반드시 체크하고 [Install Now]
  4) [Close]

  (클라우드만 쓸 거라면 이 단계는 필요 없습니다)

------------------------------------------------------------
3. 집 PC에서 실행하기
------------------------------------------------------------
  이 폴더의  실행하기.bat  을 더블클릭하세요.

  · 처음 한 번은 필요한 프로그램을 자동 설치하므로 1~2분 걸립니다.
  · 두 번째부터는 몇 초면 켜집니다.
  · 검은 창에 주소가 나옵니다.

      ============================================================
        인스타 사진 다운로더가 실행 중입니다.
        이 컴퓨터에서 :  http://localhost:5000
        폰·노트북에서 :  http://192.168.0.12:5000
      ============================================================

  · PC 브라우저가 자동으로 열립니다. (안 열리면 http://localhost:5000 직접 입력)
  · ★ 검은 창을 닫으면 프로그램이 꺼집니다. 폰에서 쓰는 동안 창을 두세요.
    (최소화는 괜찮습니다)

------------------------------------------------------------
4. 폰·노트북에서 접속 (같은 와이파이)
------------------------------------------------------------
  1) 폰이 PC와 같은 와이파이에 연결되어 있는지 확인
  2) 폰 브라우저 주소창에 검은 창에 나온
        http://192.168.0.12:5000
     주소를 그대로 입력 (숫자는 PC마다 다릅니다)
  3) 화면이 나오면 성공. 폰에서 [홈 화면에 추가] 해 두면 앱처럼 열립니다.

  ▶ 윈도우 방화벽 창이 뜨면
     [개인 네트워크]에 체크하고 [액세스 허용]을 누르세요.
     이걸 놓치면 폰에서 접속이 안 됩니다.

------------------------------------------------------------
5. 사용법 (화면 순서대로)
------------------------------------------------------------
  ① 아이디 입력
     예) nasa     (@ 없이, @nasa 라고 써도 됩니다)

  ② [사진 목록 불러오기]
     → 계정 정보와 함께 최근 사진 12개가 카드로 나옵니다.
       (날짜 · 설명 일부 · 사진 미리보기)
     → 사진을 누르면 크게 볼 수 있습니다.

  ③ 사진 고르기
     · 카드 오른쪽 위 동그라미(체크박스)를 누르면 선택됩니다.
     · [전체 선택]으로 한 번에 고를 수도 있습니다.
     · 이미 받은 사진은 흐리게 '다운 완료' 표시가 되어 있습니다.
       [안 받은 사진만 보기]를 켜면 그것들은 숨겨집니다.

  ④ 받기
     · 한 장만: 카드 아래 [원본 받기] → 그 사진만 내려받습니다.
     · 여러 장: 아래쪽 [선택한 사진 원본으로 받기] → 차례로 받고
       끝나면 [선택한 N장 ZIP으로 한 번에 받기] 버튼이 나옵니다.
     · 받는 동안 진행 막대가 나옵니다. 차단을 피하려고 사진 한 장씩
       1.5~3초씩 쉬며 받기 때문에 10장이면 30초쯤 걸립니다.

  ⑤ 더 보기
     · [다음 12개 더 불러오기]를 누를 때만 인스타그램에 추가로 요청합니다.
     · 사진은 PC의  downloads\(아이디)\  폴더에 저장됩니다.
     · 다운로드 이력은  data\history.json  에 남습니다.

  ※ 영상은 받지 않습니다. 사진만 받습니다.
  ※ 원본 화질 = 인스타그램이 보관하는 가장 큰 이미지입니다.

6. 로그인 세션 설정 (요즘은 거의 필수)
------------------------------------------------------------
  요즘 인스타그램은 로그인을 하지 않으면 프로필 사진 목록을 거의 보여 주지
  않습니다. 그래서 아래처럼 한 번만 세션을 넣어 두면 훨씬 잘 됩니다.

  ★ 내 인스타그램 계정으로 로그인한 상태에서만 가능합니다.

  [PC 크롬에서 sessionid 복사하기]
   1) 크롬에서 https://www.instagram.com 에 로그인
   2) 키보드 F12 (개발자 도구) 를 누름
   3) 위쪽 탭에서 [Application] 선택
      (안 보이면 >> 를 눌러 찾기. 영어가 아니면 [애플리케이션])
   4) 왼쪽 Storage → Cookies → https://www.instagram.com 클릭
   5) 목록에서 이름이  sessionid  인 줄을 찾기
   6) 그 줄의 Value 칸을 클릭 → 전체 선택(Ctrl+A) → 복사(Ctrl+C)
      (보통 30자 이상, 글자와 숫자)

  [앱에 넣기]
   1) 다운로더 화면에서 [인스타그램 로그인 세션] 펼치기
   2) 입력칸에 붙여넣기 → [저장하고 확인]
   3) "✅ @내아이디 계정으로 연결되었습니다" 가 나오면 성공
   4) 이제 아이디를 다시 불러오면 목록이 잘 나옵니다.

  · sessionid=...; csrftoken=... 처럼 쿠키 전체를 붙여넣어도 됩니다.
  · 화면에는 끝 4자리만 보이고, 값은 서버 메모리에만 둡니다.
  · 서버(앱)를 껐다 켜면 다시 넣어야 합니다.
    → 클라우드에서는 아래 7-E 처럼 환경변수에 넣으면 계속 유지됩니다.
  · 인스타그램에서 로그아웃하거나 비밀번호를 바꾸면 세션이 무효가 됩니다.
    그때는 새로 복사해 넣으면 됩니다.

  [명령어로 세션 파일 만들기 — 선택, 집 PC 전용]
   실행하기.bat 을 한 번 실행했다가 끈 뒤, 이 폴더에서 명령 창을 열고
       .venv\Scripts\activate
       python -m instaloader --login=내아이디
   → 비밀번호 입력 → 같은 폴더에 session-내아이디 파일이 생기면
     앱이 자동으로 인식합니다.

7. 클라우드에 올려 '링크'로 쓰기 (Render.com 무료)
------------------------------------------------------------
  집 PC를 켜 두지 않아도, 와이프분이 어디서든 링크로 접속할 수 있게
  만드는 방법입니다. 프로그램 설치 없이 브라우저만으로 할 수 있습니다.

  [7-A] GitHub에 파일 올리기
   1) https://github.com 접속 → 로그인 (없으면 Sign up)
   2) 오른쪽 위 [+] → [New repository]
   3) Repository name 에  insta-photo-downloader  입력
      → [Private] 선택(권장) → [Create repository]
   4) 화면 가운데 "uploading an existing file" 링크 클릭
      (또는 [Add file] → [Upload files])
   5) 이 폴더 안에서 아래 파일/폴더를 끌어다 놓기
        app.py
        requirements.txt
        Procfile
        render.yaml
        .gitignore
        templates  (폴더째)
        실행하기.bat
        사용설명서.txt
      ★ .venv, data, downloads, session-... 는 올리지 마세요.
        (사진·비밀값·임시파일이라 용량도 크고 위험합니다)
   6) 아래 [Commit changes] 클릭

  [7-B] Render에 연결하기
   1) https://render.com 접속 → [Get Started] → GitHub로 가입/로그인
   2) 대시보드에서 [New +] → [Blueprint]
   3) 방금 만든 저장소(insta-photo-downloader) 선택 → [Connect]
   4) render.yaml 을 읽어 설정이 자동으로 채워집니다.
      이름 확인 → [Apply] (또는 [Deploy Blueprint])
   5) 3~5분 기다리면 위쪽에 주소가 나옵니다.
        https://insta-photo-downloader-xxxx.onrender.com

   ※ [Blueprint]가 안 되거나 오류가 나면, 수동으로 만들어도 됩니다.
      [New +] → [Web Service] → 저장소 선택 → 아래처럼 입력
        Name           : insta-photo-downloader
        Region         : Singapore (한국과 가장 가까움)
        Branch         : main
        Runtime        : Python 3
        Build Command  : pip install -r requirements.txt
        Start Command  : gunicorn app:app --bind 0.0.0.0:$PORT --timeout 120 --workers 1 --threads 8
        Instance Type  : Free
      → [Deploy Web Service]

  [7-C] 접속 암호 걸기 (권장)
   1) Render 서비스 화면 → 왼쪽 [Environment]
   2) [Add Environment Variable]
        Key   : ACCESS_CODE
        Value : 1234  (와이프분과 정할 숫자 4자리)
   3) [Save Changes] → 자동으로 다시 배포됩니다.
   4) 이제 링크를 알아도 암호를 넣어야 들어갈 수 있습니다.

  [7-D] 로그인 세션을 환경변수에 넣기 (권장)
   1) [Environment] → [Add Environment Variable]
        Key   : INSTA_SESSIONID
        Value : (6번에서 복사한 sessionid 값)
   2) [Save Changes]
   → 서버가 다시 시작돼도 세션이 유지됩니다.
     (앱 화면에서 넣은 세션은 재시작하면 사라집니다)

  [7-E] 와이프분께 보내기
   · 주소:  https://insta-photo-downloader-xxxx.onrender.com
   · 암호 :  1234
   두 개만 문자로 보내면 됩니다. 폰 브라우저에서 열고 암호를 넣으면 끝.

  ★ 무료 플랜의 특징
    · 15분 동안 아무도 안 쓰면 잠이 듭니다.
      → 다음에 처음 열 때 30~50초 정도 기다려야 화면이 뜹니다. 정상입니다.
    · 서버 안의 파일(받은 사진·이력)은 다시 배포하거나 서버가 새로 뜰 때
      사라질 수 있습니다. 받은 ZIP은 그때그때 폰/PC에 저장해 두세요.
      (다운로드 이력도 초기화될 수 있어 '다운 완료' 표시가 사라질 수 있습니다)
    · 인스타그램은 데이터센터(클라우드) IP를 더 의심합니다.
      세션을 넣어도 막히면, 집 PC 방식(3~4번)이 더 안정적입니다.

8. 잘 안 될 때
------------------------------------------------------------
  ● "인스타그램이 로그인을 요구하고 있습니다 (401)"
  ● "접근을 거부했습니다 (403)"
      → 6번대로 로그인 세션(sessionid)을 넣어 주세요. 거의 이 문제입니다.
      → 넣은 뒤에도 그러면 20~30분 뒤 다시 시도하세요.

  ● "요청을 너무 많이 받았다며 잠시 막았습니다 (429)"
      → 15~30분(심하면 몇 시간) 기다리세요. 연달아 누르면 더 길어집니다.

  ● "그런 아이디의 계정을 찾을 수 없습니다"
      → 철자 확인. 계정을 삭제했거나 이름을 바꾼 경우에도 나옵니다.

  ● "비공개 계정입니다"
      → 이 앱은 공개 계정만 볼 수 있습니다.

  ● "인스타그램 보호를 위해 N초 뒤에 다시 불러올 수 있습니다"
      → 새로고침을 너무 빨리 눌렀습니다. 10초만 기다리면 됩니다.

  ● 사진 미리보기가 깨져 보입니다
      → 인스타그램 이미지 주소가 만료된 경우입니다.
        [새로고침]을 누르면 새 주소로 다시 불러옵니다.

  ● "사진 목록이 만료되었습니다"
      → 20분이 지나 목록이 오래되었습니다. 아이디를 다시 불러온 뒤 받으세요.

  ● 폰에서 화면이 안 열립니다 (집 PC 방식)
      1) 폰과 PC가 같은 와이파이인지
      2) 검은 창이 켜져 있는지
      3) 윈도우 방화벽 [액세스 허용] 을 했는지
      4) PC의 IP가 바뀌지 않았는지 (검은 창 주소 확인, ipconfig)
      5) PC에서 http://localhost:5000 이 열리는지

  ● 클라우드 주소가 안 열립니다
      → 무료 플랜은 잠들어 있어 첫 접속에 30~50초 걸립니다. 조금 기다려 보세요.
      → 그래도 안 되면 Render 대시보드에서 서비스 상태(빨간색/초록색)를 확인.

  ● "Python 을 찾을 수 없습니다" (집 PC)
      → 2번대로 Python을 다시 설치하며 "Add python.exe to PATH" 체크.

9. 꼭 지켜 주세요
------------------------------------------------------------
  · 공개 계정의 사진만 볼 수 있습니다. 비공개 계정은 받지 않습니다.
  · 받은 사진은 개인적으로 보관·감상하는 용도로만 쓰세요.
    저작권과 초상권은 사진을 올린 사람에게 있습니다.
    남의 사진을 내 것처럼 올리거나 상업적으로 쓰면 문제가 됩니다.
  · 인스타그램 약관은 자동 수집을 제한합니다. 과도하게 많이·자주 받으면
    계정이나 IP가 제한될 수 있으니 천천히 쓰세요. (이 앱은 일부러 느리게 동작합니다)
  · sessionid 는 내 비밀번호와 같은 힘을 가집니다.
    캡처·메시지로 남에게 보내지 마세요. (특히 단톡방·SNS 금지)
  · 클라우드에 올릴 때 ACCESS_CODE(접속 암호)를 꼭 걸어 두세요.
    안 걸면 링크를 아는 사람 누구나 내 세션으로 요청할 수 있습니다.
  · 집 PC 방식은 같은 와이파이 안에서만 쓰도록 만든 것입니다.
    공유기의 '포트 포워딩'으로 인터넷에 열어 두지 마세요.

10. 폴더 구성
------------------------------------------------------------
  실행하기.bat      더블클릭해서 실행
  app.py            프로그램 본체
  templates\
    index.html      웹 화면
    login.html      접속 암호 화면
  requirements.txt  필요한 프로그램 목록
  Procfile          클라우드(Render) 실행 명령
  render.yaml       클라우드 배포 설정
  .gitignore        GitHub에 올리면 안 되는 것 목록
  사용설명서.txt    이 문서
  downloads\        받은 사진 (아이디별 폴더)
  data\
    history.json    다운로드 이력 (지우면 '다운 완료' 표시가 초기화됩니다)
    cache\          목록·썸네일·ZIP 임시 파일 (자동 정리)
  .venv\            자동 생성되는 준비 폴더 (지우지 마세요)

  ※ 처음 상태로 되돌리려면 .venv 폴더만 지우고 실행하기.bat을 다시 실행하세요.
    (downloads, data 폴더는 지우지 마세요)

11. 자주 묻는 질문
------------------------------------------------------------
  Q. 영상도 받을 수 있나요?
     A. 지금은 사진만 받습니다. 영상 게시물은 목록에서 빠집니다.

  Q. 화질이 원본인가요?
     A. 네. 인스타그램이 보관하는 가장 큰 이미지를 받습니다.

  Q. 같은 사진을 또 받으면?
     A. '다운 완료'로 표시되고, 다시 받지 않고 건너뜁니다.
        (서버 폴더에 파일이 남아 있는 동안)

  Q. '다운 완료' 표시를 지우고 싶어요.
     A. data\history.json 파일을 지우면 됩니다. (사진은 그대로 남습니다)

  Q. 계정을 여러 개 받을 수 있나요?
     A. 네. 아이디만 바꿔서 다시 불러오면 됩니다.
        '이전에 받은 사진'에 계정별로 모입니다.

  Q. 사진이 120장 넘게 필요한데요?
     A. 한 번에 120개까지 목록에 담습니다. 그 이상은 계정을 나눠서 받거나
        잠시 뒤 새로고침 후 이어서 받으세요.

  Q. 프로그램을 켤 때마다 자동 실행하고 싶어요 (집 PC).
     A. 실행하기.bat 의 바로 가기를 만들어
        [Windows 키 + R] → shell:startup 폴더에 넣어 두면 됩니다.
